Simulator Tabel Kebenaran

Tulis ekspresi logika, lalu lihat setiap kemungkinan nilai variabelnya beserta hasil tiap langkah.

Bisa juga ditulis AND, OR, NOT, XOR, ∧, ∨, ¬, →, ↔. Urutan prioritas: NOT, AND, XOR, OR, →, ↔. Maksimal 6 variabel.

Contoh:

Versi Python (jalankan di komputer sendiri) 
python tabel_kebenaran.py "(P -> Q) & (Q -> R) -> (P -> R)"
python tabel_kebenaran.py            # mode interaktif
