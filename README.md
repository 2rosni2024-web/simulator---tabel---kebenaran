# Simulator Tabel Kebenaran & Verifikator Argumen

Aplikasi web untuk mata kuliah Logika (PJBL-1). Berjalan di browser tanpa instalasi.

Demo: https://2rosni2024-web.github.io/simulator---tabel---kebenaran/

## Fitur
- Membuat tabel kebenaran dari rumus logika proposisi
- Menentukan rumus tautologi, kontradiksi, atau kontingen
- Memeriksa validitas argumen (premis dan kesimpulan)
- Operator: negasi, konjungsi, disjungsi, implikasi, biimplikasi
- Tampilan nilai B/S atau 1/0

## Cara menjalankan
Buka file index.html di browser, atau kunjungi link demo di atas.
